## How to Submit a Model

1. Train a model on any environment type (1s-d, 2s-d, 3s-d, 6r-c, etc.)
2. Save the model (`.keras`, `.h5`, or RLlib `.p` pickle)
3. Open a GitHub Issue with the model attached (≤10 MB) **or** provide a Hugging Face / Kaggle link
4. The CI autograder runs 1000 games and updates this leaderboard automatically

## Local Benchmark

```bash
# Install
pip install -e .[solvers]

# Run benchmark
flopyarcade-benchmark \
  --model flopyarcade/examples/policymodels/model_3s-d.p \
  --envtype 3s-d \
  --games 1000 \
  --seed 42 \
  --output results.json
```

## Notes

- Seeds 42–1041 (1000 unique seeds per model)
- Environment uses `NAGENTSTEPS=200` (max steps per game)
- Early termination occurs when agent fails the task (reward = 0 for that game)
- 1s-d and 2s-d have median=0 (most games fail; success is stochastic)
- 3s-d has median=575 (majority of games succeed; model is more robust)
